# Live Poki art reference

Use this workflow when a game needs marketplace artwork. Do not bundle a fixed set of reference images or reuse another project's screenshot as the current market view.

1. Understand the game first: its actual visual style, core action, most recognizable character or object, tone, and intended audience. The artwork should set an honest expectation of the game.
2. Open [Poki's live homepage](https://poki.com/) with Computer Use or an available browser. Let the game tiles load, then capture a fresh screenshot of the visible grid for this project. The mixed-genre homepage is the primary reference. Record the capture date and page URL in the project's art notes or handoff; keep the screenshot with the project if a persistent reference is useful. Do not add it to this skill.
3. Look across several tiles rather than copying one. Note recurring choices that work at small size: focal subject, silhouette, composition, depth, rendering style, saturation, contrast, and how much detail survives in the grid. Treat the homepage as a current view of marketplace presentation, not proof that every visible image is optimal or a requirement to match a trend.
4. If the game's genre has a distinct visual language and the broad grid leaves a real design question unanswered, use Poki's own search or category page for a secondary screenshot. Keep the homepage as the baseline and do not make a genre result a template to imitate.
5. Turn the observations into a short art direction for this game. Combine broad, effective visual patterns with the game's own identity. Do not copy another game's character, composition, logo, title treatment, or distinctive artwork. Avoid a generic average that hides what makes this game recognizable.
6. Generate or revise the requested artwork, then inspect it at the size it will appear in the grid and beside the current homepage examples. Check instant readability, subject recognition, contrast against Poki's page, and fidelity to the actual game. Iterate if the art is muddy, misleading, or too similar to a reference.

For a Poki static thumbnail, recheck the current [official thumbnail guide](https://developers.poki.com/guide/game-thumbnail) before export and follow its latest format and design requirements. Keep requirements for other cover or icon placements distinct; do not assume one image size fits every placement. If the live site cannot be viewed or captured, report that limitation and avoid claiming a current-market comparison.
