# Web Game Creator repository

This repository is the source of the Web Game Creator Codex plugin. The installable plugin lives in `plugins/web-game-creator/`; its bundled game starter is in `plugins/web-game-creator/assets/project-template/`.

Use the relevant bundled skills when maintaining the plugin or its template: `game-init` for initialization, `game-pipeline` for stage and verification scope, `game-project-notes` for idea and playtest notes, `poki-art-reference` for marketplace artwork, `poki-sdk` for Poki integration, and `levelry-mcp` for Levelry canvas work. Read the corresponding `SKILL.md` before changing that area. These files are the plugin's source; a separate game created from the template is governed by its copied `AGENTS.md`.

Keep plugin instructions, template files, and documentation in English. Preserve the template's minimal test policy: add and run only checks tied to a concrete important risk. User requests take precedence over repository guidance.
